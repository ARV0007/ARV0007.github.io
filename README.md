# arv0007.github.io

Portfolio of Aman Raj Verma: https://arv0007.github.io

Plain HTML and CSS, no build step. GitHub Pages serves this repository as it is.

| Path | What it is |
|---|---|
| `index.html` | Home: the record, projects, open source, experience |
| `demos/transakt/` | Calls the live Transakt API from the browser (needs Transakt's CORS setting for this origin) |
| `demos/sentinel/` | Replays a recorded end-to-end Sentinel run; the data is `replay.json` |
| `assets/` | Shared styles and the light/dark toggle |
| `resume.pdf` | Current resume |

To preview locally: `python3 -m http.server` in this folder, then open http://localhost:8000.
