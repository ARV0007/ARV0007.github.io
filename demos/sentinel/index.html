How the run was graded

The simulator kept an answer key: which payments it planted, as part of which incident. eval/evaluate.py compared the system's output against it.

Each planted incident

Missed payments are all from the velocity bursts: the first few of a burst look normal until the pace gives them away. The incident still gets a case either way. A longer run with Kafka on Docker scored precision 0.947; this shorter one happened to have no false flags at all.
